# HWIS CAS System — Context

## Purpose

Give teachers an easy tool to encourage students' positive behaviors by awarding evaluation points, and provide admins oversight and reporting.

## Domain Glossary

| Term                | Definition                                                                                                                                                                                                                                                                            |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Evaluation**      | A record of a teacher giving a point value (+/-1, +/-2) to a student under a category with details. Synonymous with "point" in casual use.                                                                                                                                            |
| **Category**        | A named point category with optional merit/demerit criteria and CAS alignment. Teachers may use suggested criteria or write their own.                                                                                                                                                |
| **Teacher**         | A user with the `teacher` or `admin` role who creates evaluations. Admins can also act as teachers.                                                                                                                                                                                   |
| **Admin**           | A user with the `admin` or `super` role who manages the system (students, classes, categories, users, audits, backups).                                                                                                                                                               |
| **Super**           | A user with the `super` role — like admin, but can also promote/demote other users to/from super.                                                                                                                                                                                     |
| **Student**         | A person enrolled at the school, identified from their student-domain Google email (`s{studentId}@std.hwhs.tc.edu.tw`). Has no user account — their identity and evaluation access are derived from the email on every read, gated by **Enrolled** status.                            |
| **Pending**         | User account state — logged in via Google OAuth but not yet approved by admin.                                                                                                                                                                                                        |
| **Active**          | User account state — approved and can use the system.                                                                                                                                                                                                                                 |
| **Enrolled**        | Student status — currently attending school, eligible for evaluations.                                                                                                                                                                                                                |
| **Not Enrolled**    | Student status — left mid-year, hidden from teachers by default, visible only to admins.                                                                                                                                                                                              |
| **House**           | One of four houses (Heracles, Wukong, Ixbalam, Setna) competing on evaluation and event points. Points are the same currency regardless of source.                                                                                                                                    |
| **Event point**     | Points assigned by admin via house_events, typically after tallying external competition results.                                                                                                                                                                                     |
| **Evaluation week** | Monday–Sunday cycle. Evaluations are locked for edit/delete after the following Monday 00:00 to ensure consistency with weekly admin reports.                                                                                                                                         |
| **Viewer**          | The settled view of the signed-in client session (`useViewer()`), derived from auth + the `users.profile` query. Exposes status (`loading`/`signedOut`/`pending`/`active`), the profile, and capability/role flags (`isAdmin`, `isTeacher`, `isStudent`, `isEnrolled`, `isApproved`). |
| **CAS**             | Creativity, Activity, Service — alignment tags on point categories.                                                                                                                                                                                                                   |
